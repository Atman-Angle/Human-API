# PROJECT_LOCK.md

## 主题

# AI 时代，我们为什么还需要知乎？

## 核心洞察

AI 可以搜索、总结和重组已经存在的知识。

但 AI 无法直接生成真实人类经历，也无法观察尚未进入公开互联网的信息。

因此：

> AI 时代，知乎的稀缺价值可以从“更多答案”进一步走向“让真实的人贡献 AI 尚不知道的现实观察”。

