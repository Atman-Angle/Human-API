输入问题后的 Agent 决策流程

先判断问题复杂度；复杂问题先判断圈子，再在已有圈子内判断帖子。

01 · 用户输入问题建立一次搜索与求证任务
02 · 理解问题并判断复杂度提取主题、对象和关键词，判断是否需要社区知识
是否为简单问题？

是：简单问题

03S · Agent 直接生成回复事实明确、范围清晰，不检索知乎、不匹配圈子、不创建帖子
04S · 展示简洁答案完成本次请求

否：复杂问题，进入社区求证

03C · 匹配对应圈子先根据主题和语义相关度检索已有圈子
是否找到合适的圈子？

是：进入已有圈子

04A · 在圈内查找相关帖子只有确认圈子存在后，才判断有没有帖子可以回复问题
圈内有可回复帖子？
05A · 有：展示已有帖子复用帖子检索补充知乎观点更新求证面板
05B · 无：创建对应帖子检索知乎高相关内容，整合观点后在当前圈子发帖

否：没有合适圈子

04B · 创建新圈子生成圈子名称、简介和主题边界
05C · 检索知乎高相关内容收集知识丰富的帖子、回答和不同观点
06C · 整合观点并创建对应帖子在新圈子中发布第一个帖子，并生成求证入口
关键顺序：节点 2 先判断简单/复杂；复杂问题进入节点 3 匹配圈子。找到圈子后，才进入“圈内查找帖子”的第二次判断；没有圈子则跳过帖子判断，直接创建圈子、检索知乎、整合观点并创建帖子。
